# 🏺 穿越朝代大冒险

历史 × 地理 闯关网页游戏——从夏商周一路穿越到明清,答题收集「传世宝物」。
为家里的两位小玩家(哥哥和妹妹)定制,主打**兄妹双人对战**。

**▶ 在线游玩:https://dami2ky.github.io/dynasty-quest/**

## 玩法

- **🏔️ 单人闯关**:8 个朝代关卡,每关 3 题(限时 20 秒 / 3 颗心),通关收宝物、评星级,
  全收集达成「时空探险大师」结局
- **⚔️ 双人对战**:两位玩家轮流答题,答对 +10 分、手快最多再 +5 分,历史战绩累计
- 每题答完有「你知道吗?」小知识;支持电脑 / iPad / 手机浏览器

## 本地运行

零依赖、零构建:下载本仓库,双击 `index.html` 即可游玩;
或 `python3 -m http.server` 后访问 `http://localhost:8000`。

## 题库外挂包(本游戏的扩展机制)

任何知识都能整理成「题库包」挂进游戏,让孩子玩到的题越来越多:

- 规范见 [PACK-SPEC.md](PACK-SPEC.md)(题目格式 + 三步接入 + 上手示例)
- 已内置:**课本诗词包**(343 题,一年级到高三,接下句 / 作者题型)
- 核心题库 `questions.js` 24 题 + 外挂包 = 367 题
